# Day 7 - Command-Line Basics

## Objective

Learn how to navigate directories and manage files using Git Bash.

## Commands Practised

| Command | Purpose |
|---|---|
| `pwd` | Display the current directory. |
| `ls -la` | List all files, including hidden files. |
| `cd` | Change the current directory. |
| `mkdir -p` | Create a directory and its parent directories. |
| `touch` | Create an empty file. |
| `echo` | Output text or write text to a file. |
| `cat` | Display the contents of a file. |
| `cp` | Copy a file. |
| `mv` | Move or rename a file. |

## Redirection Operators

- `>` writes text to a file and replaces its existing contents.
- `>>` adds text to the end of a file.

## Mistake and Fix

I accidentally created `notes..txt` instead of `notes.txt`. I learned that they are two different valid filenames. I used `cp` to create a backup and `mv` to correct the filename.

## What I Learned

I learned how to navigate directories and manage files in Git Bash. These commands are also commonly used in Linux and cybersecurity work.
